EXTENSION / PROPOSED WORK:
----------------------------------------------

1. Knowledge Graph-Based Extension
   - The proposed system extends the existing career prediction approach with a Knowledge Graph.
   - Represent careers, skills, concepts, courses and prerequisites.
   - Establish relationships between career requirements and learning concepts.
   - Use prerequisite relationships to determine the correct learning sequence.

2. ML-Integrated Career Prediction
   - Integrate the trained ML career prediction model into the application.
   - Use user assessment responses as input features.
   - Predict the initial career path.
   - Provide alternative career paths when the predicted path is not accepted.

3. Competency-Aware Graph Extension
   - Integrate learner competency with the Knowledge Graph.
   - Identify the learner's current knowledge and skill gaps.
   - Use prerequisite relationships to prioritize missing concepts.
   - Generate a personalized learning path based on the learner's current competency.

4. LLM-Based Roadmap Extension
   - Integrate Gemma 3:1B as the LLM layer.
   - Use the generated learning path and Knowledge Graph information as context.
   - Generate a complete career roadmap.
   - Provide tutorials, courses, learning materials, projects and study guidance.
   - Personalize roadmap content according to the learner's progress.

5. AI Assessment Extension
   - Generate AI-based MCQs and quizzes.
   - Generate questions based on the learner's current concepts.
   - Store assessment and performance history.
   - Use assessment results for competency updates.

6. Adaptive Learning Extension
   - Update learner competency after assessments.
   - Update the Knowledge Graph with learner progress.
   - Recalculate skill gaps.
   - Recalculate learning priorities.
   - Dynamically update the learning path and recommend the next activity.

7. Overall Proposed Extension
   - Existing approach: ML-based career prediction.
   - Proposed extension: ML + Knowledge Graph + Competency Analysis + Prerequisite Reasoning + Personalized Learning Path + Gemma 3:1B.
   - The Knowledge Graph provides the structural relationship between careers, skills, concepts, courses and prerequisites.
   - ML provides the initial career prediction.
   - Competency analysis identifies the learner's skill gaps.
   - Graph-based reasoning determines prerequisite-aware learning order.
   - Gemma 3:1B converts the structured learning path into a personalized career roadmap and learning guidance.
   - Continuous assessments update the learner model and enable adaptive learning.
